Layout & spacing

  • main: single centered column, max-width --w-column (900px), padding 16px top, 20px sides, 24px bottom.
  • main.wide: max-width --w-wide (1400px), for pages with side-by-side columns. Use it with .split (or an interactive's own grid), not for plain text pages.
  • The site bar and title bar read the same two variables, so they always line up with main.
  • Spacing follows an 8px grid. Bars below show the common steps.
  • Headings have 24px above and 8px below. A heading that's the first thing in its container (page, card, section) has no space above.

Site bar, title bar & controls

Drawn by shared/theme.css and wired by shared/ui.js (markup, the <head> order and options are at the top of that file). Every page starts with the site bar; every interactive page has the title bar below it.

Page templates

  • Column: <nav class="sitebar"> + <header class="topbar"> + <main> (900px). Reading-heavy pages, quizzes, small interactives.
  • Split: <nav class="sitebar wide"> + <header class="topbar wide"> + <main class="wide"> with .split (1400px; 2/3 play area, 1/3 side panel). Below 1000px the panel stacks, so text needed while playing also goes next to the play area.
  • Stage: the same as Split, with one area (1400px). Extras open in a modal.
  • <head>: shared/theme-init.js (not deferred, before the CSS), the favicon links, theme.css, style.css, then shared/data/topics.js, shared/data/interactives.js, shared/ui.js, script.js (all defer). No font links.

Site bar

The dark band at the top of this page. Pages write an empty <nav class="sitebar" aria-label="Site"></nav>; ui.js fills it. Its contents line up with main.

  • Left: the home link (Ψ + the site name). The home page's placeholder has data-home, so it has no home link.
  • Right: the course menu, then the light/dark switch. The switch's label says what it will do: "Switch to dark mode" (moon) or "Switch to light mode" (sun).
  • Course menu: a labeled <select> (Regular, Dual Credit, AP) listing the courses marked offered in topics.js, or every course with ?dev. It's left out while only one course is offered. "Course" shows from 760px and is read to screen readers only below that. The choice is saved on the device; a ?course= link wins and is saved too. Pages read it with APPSYCH_UI.course.
  • Dark mode follows the device until the switch is used; the choice is then saved on the device and carries to every page and open tab. Switching to the device's own mode goes back to following the device.
  • First Tab press: "Skip to activity", a link to main that shows only when focused.
  • Hidden when printing; printing always uses the light colors.

Settings

Rarely changed options go here, such as light colors.

  • Left: the page's h1 and ⓘ (description, how to play, class unit and CED topic). Center: .modes with .mode buttons (aria-pressed), only for interactives with 2+ modes. Right: data-ui="sound", then data-ui="settings", then data-ui="fullscreen", each only if used.
  • Sound starts off on every page load. Scripts check APPSYCH_UI.sound.on.
  • Popovers close with Escape (focus returns to the button) or a click outside.

Full screen

Only Stage and Column activities get it. Two kinds, chosen by the activity:

  • Whole page: <button class="icon-btn" data-ui="fullscreen">. The site bar and title bar stay (modes, sound, settings and ⓘ still work) and the 1400px limit is lifted. For projector games. Try it on the Memory Span example above.
  • The activity's card: add data-target="<id>". Only that element fills the screen, on --bg, with an exit button in its corner; the activity's own :fullscreen CSS decides how it grows. Modals still show; title-bar popovers don't. Try it below.
  • Escape exits both; the button's label and icon follow. Hidden where the browser can't do it (iPhone Safari). APPSYCH_UI.fullscreen.onChange(fn) lets a canvas resize.

Accessibility

:focus-visible
  • Focus outline: 3px --heading, 3px offset (--sitebar-text in the site bar). Shows on keyboard focus for buttons, links, and form fields.
  • The first Tab on every page reaches "Skip to activity", which jumps past the site bar and title bar to main.
  • hidden attribute always hides an element, even one with its own display setting.
  • When a device has "reduce motion" on, button transitions and press-shrink are turned off.
  • Don't rely on color alone: pair colors with a label, icon, or pattern.
